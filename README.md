# Open Harness

**The first fiduciary-execution benchmark for exchange agents.**
首个面向交易所场景的 Agent「受托执行」评测基准。

> 🚧 v0.1 in development. Full bilingual README lands with the release (see `specs/00-milestones.md` · FP12).

## Disclaimer / 免责声明

All evaluation runs against a **deterministic mock exchange** (default) or the **Binance Spot Testnet**
(fake funds). No code path touches mainnet write endpoints. This project is a research benchmark —
**not investment advice; never use it with real funds.**
